## Overview

The **Team 6 Task Planner App** is built to simplify task management for collaborative projects. With its user-friendly design and interactive features, the app empowers teams to:
- Create, assign, and track tasks.
- Set deadlines and priorities.
- Collaborate effectively and boost productivity.

Whether you're managing personal projects or working with a team, this app is designed to meet your task planning needs.

---

## Features

- **Task Management**: Add, edit, and delete tasks with ease.
- **Team Collaboration**: Assign tasks to team members and track progress.
- **Priority Levels**: Organize tasks by priority to focus on what matters most.
- **Deadline Tracking**: Set deadlines to ensure timely task completion.
- **Responsive Design**: Optimized for desktops, tablets, and mobile devices.
- **Lightweight and Fast**: Built with minimal dependencies for high performance.

## Getting Started

To get started with the **Team 6 Task Planner App**, follow these steps:

### Prerequisites

Ensure you have the following software installed:
- A modern web browser (e.g., Chrome, Firefox, Edge)
- [Git](https://git-scm.com/) (optional, for cloning the repository)

### Installation

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/reuben-idan/Team-6-Task-Planner-App.git
   ```

2. **Navigate into the Project Directory**:
   ```bash
   cd Team-6-Task-Planner-App
   ```

3. **Open the App**:
   Open the `index.html` file in your browser or use a live server tool to launch the app.

---

## Usage

1. **Launch the Application**:
   Open the `index.html` file in your browser to load the app.

2. **Create Tasks**:
   - Click on the "Add Task" button to create a new task.
   - Fill in the task details, including title, description, priority, and deadline.

3. **Assign Tasks**:
   - Assign tasks to team members for better collaboration.

4. **Track Progress**:
   - Mark tasks as completed and monitor the progress of your projects.

5. **Customize (Optional)**:
   - Modify the source code to add custom features or styles.
